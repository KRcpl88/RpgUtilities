## What exists now (milestones 1–12)

- **`map-editor/index.html`**: the editor shell (toolbar, tool panel, canvas, properties panel, status bar) with sixteen modules.
  - `Util` (DOM-free): vector helpers, `Center`, `Boundary`, `Require`, `CreateRng` (mulberry32), `HashIntegers`, `FormatNumber`, and 2D geometry: `PolygonArea` (signed, CCW positive), `ClipPolygonToConvex` (Sutherland–Hodgman), `ClipSegmentToConvex` (returns `[t0, t1]` or null), `PointInConvex`.
  - `Projection` (DOM-free): a 1:1 port of the Python geometry, net and `Validate`, plus panel frames and seams. Exports `g_North`, `g_SectorLabels`, `g_SectorNames`, `g_dXlHexMiles`, `Build()`, `MilesPerEdge(nHexes)`, `FindSeam(szA, szB)`, `SolidToFrame`, `FrameToSolid`, and 2D transform helpers (`ApplyTransform`, `ComposeTransforms`, `InvertTransform`, `RigidFromSegments`).
  - `Lattice` (DOM-free): scale tables (`g_Scales`, regional S/M/L/XL = 1/6/36/216 mi; local S/M/L/XL = 1/10/100/600 yd), flat-top offset ↔ axial ↔ cube ↔ point, `CubeRound`, `HexPolygon` (CCW from due east), `PointToOffset`, neighbours in order N, NE, SE, S, SW, NW (`g_rgrgnDirections`), `SharedEdge`, `OffsetDistance`, `NestOffset(q, j, r)`. Offset `(q, j)` centre = `(q·w, (j + ½·odd(q))·d)`.
  - `Topology` (DOM-free): `Build(n = 24, 'XL' | 'L')` (cached) returns `{ n, szScale, dD, dW, dHexArea, nTiles, rgTiles, Panels, rgnAdjacencyOffsets, rgnAdjacency }`.
    - Each tile: `{ nIndex, szPanel, nColumn, nRow, nLatticeColumn, nLatticeRow, rgdCenter, dArea, fPartial, rgPieces }` (frame edge units; plan §11.15–16).
    - `Panels[sz]`: `{ Lattice, nFirstTile, nTileCount, nColumns, nRows, nLatticeColumnMin, nLatticeRowMax, szWest, szEast }`.
    - Helpers: `TileAt(Topo, szPanel, [east, north])`, `LocateLattice`, `TileByColumnRow`, `Neighbors`, `AreAdjacent`, `TilePolygons`, `PanelLattice`, `LatticeCenter`, `LatticeNearest`.
    - Equatorial lattices are anchored on XL centres so finer scales nest (§11.14).
  - `Coordinates` (DOM-free): `TileToUniversal` / `UniversalToTile` (miles; returns −1 beyond 0.25·d), `FormatUniversal` (`Eta 187.1W 324.0N`), `ParseUniversal`, `PanelIdByName`, `MakeLocation`, `CreateLocalMap`, `LocalTileToUniversal`, `UniversalToLocalTile` (local x east, y south; regional anchors snap to the global lattice, §11.18). `LocalTilePoint` / `LocalPointToTile` convert normalized local world points and full-hex hits, independently of the file-coordinate snap threshold. Dimensions/reference n use positive safe integers; anchors and parsed distances must be finite.
    - True coordinates (display only, plan §11.62): `TrueCoordinates(Location, milesPerEdge)` → `{ dLatitude, dLongitude, dNorthBearing }` (degrees; bearing of true north from panel north, clockwise positive, null at a pole); `FormatTrue(True, decimals = 3)` (`35.26°N 30.00°W`); `TrueDecimals(hexMiles, milesPerEdge)` (about 0.1 hex, 1–9 decimals). The prime meridian is the (+1, +1, −1) direction; longitude runs west along the strip (Alpha 30°W … Zeta 30°E).
  - `Terrain` (DOM-free): `g_rgTerrains` (17 frozen `{ nId, szChar, szKey, szName, szColor, fWater, Embellish }`, ID = row of plan §5, water = 0; `Embellish` is a frozen `{ szLayout: scatter | tile | field, dDx, dDy, dChance, szInk, szAccent, szBody }` pattern descriptor (plan §8, §11.58), or null for water, lakes, firth and plain), `g_szReservedChar` (`_`), `g_nWaterId`, `ById`, `ByChar`, `ByKey`, `IsValidId`, `IsWater`, and `g_rgLandmarkTypes` (village … dungeon) with `LandmarkType`, `IsLandmarkType`.
  - `Model` (DOM-free): `CreateGlobalMap({ nPanelHexes = 24, szTileScale = 'XL', szName })` and `CreateLocalMap({ nWidth, nHeight, szSystem, szScale, Anchor, nPanelHexes?, szName })`.
    - Document: `{ nVersion, szKind, szName, Global | Local, Topo (global only), nTiles, rgnTerrain: Uint8Array (water), Landmarks: Map<tile, {szType, szName, szNotes}>, rgOverlays: [{szId, szType, szName, szStyle, rgnTiles}], rgLabels: [{szId, nTile, szText, szCategory, dSize, dRotation, dDx, dDy}], nRevision }`. The document is mutable; its items are frozen and replaced on edit.
    - Mutators validate, apply, and return a change record `{ szLayer, Key, nIndex, Before, After }` or null for a no-op (plan §11.20): `SetTerrain`, `SetLandmark` (place/replace/edit; null removes), `RemoveLandmark`, `AddOverlay`/`UpdateOverlay`/`RemoveOverlay` (paths of adjacent tiles), `AddLabel`/`UpdateLabel`/`RemoveLabel`. `ApplyChange(Doc, Change, fForward)` replays a record and bumps `nRevision`.
    - Queries: `TileToUniversal`, `HexMiles`, `MilesPerEdge` and `TrueCoordinates(Doc, tile)` (both map kinds; local maps use their anchor panel and reference n), `IsTile`, `Neighbors`, `AreAdjacent` (Topology for global maps; lattice offsets for local maps), `LocalTileIndex`/`LocalTileXY` (index = y·width + x), `GetTerrain`, `GetLandmark`, `GetOverlay`, `OverlaysAt`, `GetLabel`, `LabelsAt`.
  - `History` (DOM-free): `Create(Doc, { nLimit = 500 })`, `Begin`/`Record`/`Commit`/`Cancel` (a brush stroke is one command; repeats coalesce), `Perform(H, szLabel, (Doc, fnRecord) => …)`, `Undo`, `Redo` (return the command so the UI can redraw its tiles), `CanUndo`, `CanRedo`, `Clear`. A new command clears redo (plan §11.24).
  - `View` (DOM-free, plan §11.26–31): the camera and layouts.
    - Camera `{ dCenterX, dCenterY, dScale (px per world unit), dMinScale, nWidth, nHeight }`: `CreateCamera`, `ResizeCamera`, `ClampScale` (default 4…400000; fit can lower the minimum for large maps), `WorldToScreenTransform`, `WorldToScreen`, `ScreenToWorld`, `Pan`, `ZoomAt` (keeps the cursor point fixed), `CenterOn`, `FitBounds`, `VisibleBounds`.
    - Bounds `[minX, minY, maxX, maxY]`: `BoundsOf`, `BoundsIntersect`, `UnionBounds`, `TransformBounds`.
    - Layouts (cached): `BuildNetLayout()` (18 placements at `rgdFrameToNet`) and `BuildFocusLayout(sz)` (neighbours through their seams, the focus panel last with the identity). A placement is `{ szPanel, szName, rgdFrameToWorld, rgdWorldToFrame, rgrgdFrameOutline, rgrgdOutline, rgdBounds, rgdCenter }`. `FindPlacement`, `PlacementAt` (the topmost placement containing a world point).
    - Local geometry (§11.48–49): `MapGeometry(Doc)` returns global topology or a cached rendering-only local adapter (one world unit per hex height; one identity placement). `MapLayout(Doc)` returns net/local layout; `FrameOutline` returns the panel polygon/local bounding rectangle. `Doc.Topo` stays null locally, and model adjacency stays independent. Bounds include full edge hexes, but empty corners do not hit a tile.
    - `PanelTileGroups(Topo, sz)` (cached): the panel's own tiles plus, for equatorial panels, the overhanging edge columns of the west/east strip neighbours with the seam transform. `VisibleTiles(Topo, Group, frameBounds)` culls by tile centre ± hex radius.
    - `HitTest(Topo, Layout, world)` → `{ nTile, szPanel, rgdFrame, szDrawPanel }` or null. It is exact, including partial pieces. `szPanel`/`rgdFrame` are the owning tile's panel and frame. A point inside an equatorial panel that falls in the tip of the strip neighbour's edge hex belongs to that neighbour's tile (plan §11.28, `prompt.md` "Map projection").
    - `DemoTerrain(Topo, nSeed)`: a deterministic `Uint8Array` world that uses all 17 terrains.
    - Feature geometry (§11.43–45, §11.55): `PanelTransform`, `FeatureCopies`, `FeatureAnchor`, `OverlayCurves` (cached per immutable overlay; cubic segments per drawing panel), `CubicPoint`, `SplitCurve` (exact half-parameter de Casteljau split), `FlattenCurve` (half-pixel tolerance), `DistanceToSegment`, `LabelTransform`, `g_dLabelUnitsPerHex` (48), `g_OverlayStyles` (shared canvas/export styles). Curves and text/glyph copies cross seams through panel transforms, not net-space lines across cut edges. Partial tiles use a visible-piece anchor without changing saved coordinates or ownership.
  - `Edit` (DOM-free, plan §11.32–35, §11.41–42): terrain and feature editing logic.
    - `g_nMaxBrushRadius` (5); `BrushTiles(Doc, nCenter, nRadius)`: tiles within r adjacency steps, nearest first (crosses seams; 3r(r+1)+1 tiles in the interior).
    - `FloodRegion(Doc, nStart)`: the connected same-terrain region (BFS, no cap); `SegmentTiles(Topo, Layout, from, to)`: tiles under a world segment, sampled every d/4 with `View.HitTest`, without consecutive repeats.
    - `PaintTiles(Doc, rgnTiles, nId, fnRecord)` → changed tiles.
    - Strokes: `BeginStroke(History, nId, nRadius)` opens a `Paint <terrain>` command; `StrokeTo(Stroke, Layout, world)` stamps the brush on each new tile along the segment from the last point and returns the changed tiles; `EndStroke` commits (null if nothing changed).
    - `Fill(History, nStart, nId)` → `{ Command, rgnTiles }` as one `Fill <terrain>` command (Command null for a no-op); `CommandTiles(Command)` lists the terrain tiles a command changes (for redraws after undo/redo).
    - `FindPath(Doc, nFrom, nTo, Excluded = new Set())`: deterministic shortest A* path across the tile graph; unit cost, safe solid-space lower bound globally and hex distance locally; throws if unreachable.
    - `GetFeature(Doc, Selection)` / `SetFeature(History, szLayer, Key, Props)`: query or undoably create/edit/delete; null Key creates labels/overlays, landmarks use a tile key, null Props deletes. Identical edits are no-ops.
    - `ExtendOverlay`, `InsertOverlayPoint`, `RemoveOverlayPoint`, `SplitOverlay`, `JoinOverlays`: every operation is one command. Removal reroutes around the removed interior tile; split shares the junction; join orients chosen endpoints, fills any gap and keeps the first path's properties.
  - `FileFormat` (DOM-free, plan §6 and §11.38–39; full spec in [`file-format.md`](file-format.md)): `Write(Doc)` → canonical `*.map.txt` text; `Parse(szText)` → a new Doc (`nRevision` 0), or throws an Error with `nLine` (0 = whole file) and the message `Line N: …`.
    - Sections: `[map]`, `[legend]`, a `[panel <Name>]` per panel in Greek order (`columns`, `rows`, `latticeColumn`, `latticeRow`, grid lines north first, `_` = not a tile) or one `[local]`, then `[landmarks]`, `[labels]`, `[overlays]` with universal coordinates. Overlay points may leave out an unchanged panel.
    - Also exports `g_szMagic` (`# RPGMAP 1`), `g_szFileExtension` (`.map.txt`), `Quote`/`Tokenize` (quoted strings with `\"`, `\\`, `\uXXXX`), `CoordinateDecimals(hexMiles)` and `FileName(Doc)`.
  - `Regions` (DOM-free, §11.52–53): `Outline(Doc, panel)` and `Build(Doc, panel?)` produce normalized export geometry (one unit per hex height, y north/up). `Build` returns `{ szPanel, rgrgdOutline, rgdBounds, rgrgdPoints, rgCells, rgEdges, rgRegions, rgShorelines }`; local scope defaults to `local`, global scope is required.
    - Cells retain tile ownership, terrain id and vertex/edge references; shared edges have one or two cell indices. Same-terrain cells flood-fill within the selected scope, including overhanging equatorial neighbours and partial pieces.
    - Regions contain `{ nTerrainId, rgnTiles, rgrgrgdLoops }`; loops repeat their first point, with outer loops CCW and holes CW. Interior edges cancel. Spatial buckets merge vertices within `g_dTolerance = 1e-8` hex; malformed boundaries throw.
    - Each cell also records its `nRegion` index.
    - `TracePaths(edges, points)` returns `{ rgrgdPoints, fClosed }` chains/loops. Shorelines include only shared water/land edges, never exterior cuts or land/land and water/water boundaries. `SmoothPath(path, passes = 2)` applies endpoint-preserving Chaikin smoothing (0–3 passes).
  - `Embellish` (DOM-free, §11.58–61): `Build(Regions.Build(...))` → per-region `null | { szKey, nTerrainId, rgInstances: [{ nVariant, rgdPoint, dScale }], rgrgrgdTrunks: [[base, top]…] }` in hex units (y up), sorted north to south; `Motifs(szKey)` → 4 cached frozen variants of `{ szRole: body | ink | accent | dot, rgrgdPoints, fClosed }` shapes; `PanelSeed`; constants `g_nVariants`, `g_dJitter`, `g_dHexArea`, `g_dTrunkSpacing`, `g_dTrunkHeight`, `g_dSouthFacing`, `g_dCrownClearance`, `g_dFringeSpacing`.
    - Scatter lattices (staggered rows, jittered, kept inside their cell) and field brick rows are anchored in the panel/local frame, so patterns continue across same-terrain tiles; mountain peaks are one motif per tile at its visible centroid, shrunk for partial tiles. Randomness is `HashIntegers(panel seed, terrain, i, j)` only.
    - Forest: trunks every 0.08 hex along internal forest/non-forest edges whose outward normal points south (y ≤ −0.3), never on export borders; crowns within 0.165 hex of such an edge are replaced by a fringe row along it (0.2 hex spacing).
  - `SvgExport` (DOM-free, §11.54–57, §11.59): `Write(Doc, { szPanel?, nWidth?, Layers? })` → deterministic self-contained SVG; `Dimensions(Doc, panel?, width?)` → `{ nWidth, nHeight, dWidth, dHeight, rgdBounds }`; `FileName(Doc, panel?)`; XML `Escape`; `g_Layers`, `g_nDefaultWidth` (1600) and `g_dHexUnits` (48).
    - `Estimate(Doc, panel?, embellish = true)` → `{ nTiles, nEmbellished, nBytes }`: an upper-bound size of 4 KB + 4 B per tile + `g_nEmbellishedTileBytes` (1,100) per embellished tile (§11.64).
    - A selected global panel is north-up and clipped; local maps export whole. The viewBox has 48 units per hex, independent of physical scale, and output height follows width/aspect ratio.
    - Terrain uses even-odd region paths/use; shorelines are smoothed, the optional hex grid has unique edges. Roads/trails and tapered rivers reuse shared curves/styles. Glyph symbols/use and haloed labels retain partial-tile anchors, seam transforms, category/rotation/offset units. Landmark names are optional.
    - The `embellishment` layer sits between terrain and shoreline: one `<g data-terrain>` per region clipped by `clip-region-N` (`<use>` of its even-odd region path); used motif variants are defined once as `emb-<key>-<n>` and placed with `<use>` (scaled for partial peaks); forest trunks are one path per region. Filled motifs use the descriptor body or terrain colour, or white with colours off.
    - `Layers` boolean keys: `terrain`, `embellishment`, `shoreline`, `grid`, `road`, `trail`, `river`, `landmark`, `landmarkNames`, `label`; all default on except grid/names. Disabled groups are omitted. No external files or mutation of the model/history. XML-invalid text and invalid settings throw explicitly.
  - `Renderer` (`data-dom="true"`): `Create(Canvas)`, `Draw(R, State)` → `{ fRaster, dHexPixels }`, `DrawMinimap(R, MiniCanvas, State)`.
    - Tiles are drawn per placement through frame → world → screen, clipped to the panel polygon, and batched by terrain colour in chunks of 512.
    - Below 4 px, cells are filled as w × d rects; below 3 px, a cached raster of the layout is used. The hex grid appears from 8 px (at 6 px it doubled L-scale frame times for barely visible lines).
    - Then: focus-view neighbour dimming, panel outlines (the focus panel in yellow), panel names, and the hovered tile.
    - The minimap shows the net/local raster with the view rectangle, or the focus panel outline. Local maps skip panel names and use a rectangular map outline.
    - `MarkTilesChanged(R, Doc, rgnTiles)`: after an edit, cached rasters repaint just those tiles (integer-pixel boxes in every placement that draws them) on the next draw; above 3,000 tiles the raster is redrawn in place (plan §11.37). Colour buckets paint in terrain-id order.
    - The brush footprint (`State.rgnPreviewTiles`) is outlined with the hovered tile.
    - Features: smooth blue rivers, brown roads, dashed trails, eleven distinct landmark vector glyphs (`Terrain.g_rgLandmarkTypes[].szPath`), haloed labels with panel-relative size/rotation/offsets, selection outlines and label handles. Each panel clips its transformed copies, including cut-edge continuation.
    - `FeatureVisible` and `HitFeature(R, State, screen, filter)`: picking uses `R.rgFeatureHits` from the last draw and the topmost containing panel; hidden features do not enter the hit list. Label drag previews never mutate the document.
    - Feature-only changes call `MarkTilesChanged` with `[]`, retaining terrain rasters while updating their revision.
  - `App` (`data-dom="true"`, v1.0.0): `State { Doc, History, Layout, Camera, Layers, nHoverTile, rgnPreviewTiles, szTool, nTerrainId, nBrushRadius, Stroke, Selection, LabelPreview, LabelDrag, szMessage, … }`, starting with `Model.CreateGlobalMap()` (n = 24, XL) seeded with `View.DemoTerrain`.
    - Toolbar: New, Open…, Save (plan §11.40), Export SVG (§11.56), Net view, Focus panel select, Fit all, Fit panel, Undo, Redo (disabled when unavailable). Tool panel: Pan / Brush / Fill / Pick buttons (`aria-pressed`), the brush radius slider (0–5, Brush only) and the active terrain swatch; then layer toggles (terrain, hex grid, panel outlines, panel names). The properties panel's terrain legend is the active-terrain picker (click or Enter/Space; default plain).
    - Input (plan §11.36): the left button drives the tool (Brush strokes, Fill click, Pick click; Alt+click picks with any tool); middle/right drag, Space+drag or the Pan tool pans; the wheel zooms about the cursor; a double-click focuses a panel (Pan tool only); a minimap click recentres or refocuses. Keys: `H B G I` tools, `[ ]` radius, Ctrl+Z, Ctrl+Y / Ctrl+Shift+Z, Ctrl+S, Ctrl+O, arrows (Shift ×4), `+ = -`, Home, `F`, `N`, `P`.
    - Status bar: the hovered tile's universal coordinate · panel (letter) col/row (partial) · terrain · tile #, plus the last action (`Paint Forest: 116 tiles`, `Undo Fill Desert: 1,999 tiles`), the view, n/scale, tile count, hex px (raster) and version.
    - Feature tools (§11.46): Path (`O`), Landmark (`K`), Label (`T`), Select (`V`), Erase (`E`). Properties switches from the terrain legend to item fields and an overlapping-feature chooser. Path operations include explicit New/Extend/Insert/Remove/Split/Join/Finish controls; Escape finishes. Delete/Backspace deletes the selected visible item.
    - Label size and offsets are in 1/48-hex units. White/yellow handles move/rotate a preview; pointer-up commits one undo step; Escape/cancel/lost capture discards it. New label permits multiple labels per tile.
    - Layer toggles include roads, trails, rivers, landmarks and labels. Select/Erase can target a single layer/type; hidden features are protected. Terrain erase changes only the clicked tile to water. Status includes the hovered tile's landmark, overlays and labels.
    - Files (§11.40, §11.47–51): New opens a native dialog for global/local kind, name, scale, dimensions and anchor/reference n, with validation and a snapped/free-anchor preview. Create asks before discarding unsaved changes; Cancel preserves the map. Newly created maps are dirty even before editing. Open and Restore accept either kind, reset history/selection/layout and fit the map; errors keep the current document. Save downloads `FileFormat.FileName(Doc)`. Dirty state is `Doc.nRevision ≠ State.nSavedRevision`; the status bar starts with `name *`.
    - Local viewport: every terrain/feature tool, label handle and layer toggle works in normalized local coordinates; status and path properties show universal miles at the file precision and the actual mi/yd scale. Net/focus controls and panel names are disabled. Fit all and the minimap navigate the local rectangle.
    - Autosave: 2 s after the last edit (and on `pagehide`) a dirty map goes to `localStorage['rpgmap.autosave']` as `{ szText, nTime }`; Save/Open clear it, and New replaces it with a fresh scheduled autosave. On start a banner offers Restore or Discard (`#restore-banner`).
    - Export: `ExportMap()` opens `#export-map-dialog`; panel/whole-local scope, positive integer width, layer toggles and a filename/dimension preview. Visibility defaults follow the canvas but remain independent. Successful export downloads SVG without marking the map saved; Cancel/errors preserve all editing state. New and Export share modal shortcut protection; Save and Export share `Download`.
    - Polish (§11.63–64): the status bar and the selected landmark/label Properties show true latitude/longitude and the true-north bearing. Export, New and Open show a busy message and disable dialog buttons (`aria-busy`) until the work, deferred past the next paint, finishes; the export dialog warns when `Estimate` reaches 4 MB, and a finished export reports MB and seconds.
    - Exports `RpgMap.App = { g_szVersion, State, Start, ShowFocus, ShowNet, FitNet, FitPanel, SetTool, SetTerrain, SetBrushRadius, UndoOrRedo, NewMap, SaveMap, ExportMap, Autosave, IsDirty }`.
- **`Projection.Build()`** runs once, validates, and returns a deep-frozen object:
  - `Vertices`, `Faces`, `Edges`, `NetVertices`, `NetFaces`, `NetEdges` with the same IDs, order and fields as the golden JSON (edge maps are keyed `"V01|V09"`);
  - `rgszStrip` (net left to right), `rgszEquatorialWestToEast` (Epsilon … Zeta), `Validation`, `dEquatorialWidth` (1.759306);
  - `Panels[faceId]` = `{ szId, szLetter, szName, szKind, fEquatorial, Frame }`, and `Frames[faceId]`;
  - each frame: `rgdOrigin3D` (panel centre), unit `rgdEast3D`/`rgdNorth3D`/`rgdNormal3D`, `rgrgdPolygon` (frame `[east, north]` in edge units), `rgdOriginNet`/`rgdEastNet`/`rgdNorthNet`, `rgdFrameToNet`/`rgdNetToFrame`, and `szNorthVertex`/`szSouthVertex` (null for equatorial panels);
  - `Seams`: 48 entries `{ szEdge, rgszVertices, szPanelA, szPanelB, rgdAToB, rgdBToA }`.
- **Transforms** are `[a, b, c, d, e, f]` (canvas/SVG layout): `x' = a·x + c·y + e`, `y' = b·x + d·y + f`. Units are edge lengths; multiply by `MilesPerEdge(n)` for miles (plan §11.12).

### Rules

- Don't change the projection geometry in `tools/generate_map_projection.py`, and don't hand-edit the `doc/equilateral-chamfered-cube.*` files. If the tool changes, regenerate them with `--labels`.
- Everything the browser runs lives in `index.html`: no external JS, CSS, fonts or images.
- Follow the naming style: PascalCase functions; Hungarian prefixes `sz`, `d`, `n`, `f`, `rg`, `g_`.
- Output must be deterministic (SVG, file writer, any randomness): use `Util.CreateRng` / `Util.HashIntegers`, never `Math.random`.

### Gotchas found so far

- Inside module code, never write a literal `</script>`, because it ends the HTML element; write `'<\/script>'`. Also avoid a literal `<!--`, for example an SVG comment: `_load.cjs` blanks out HTML comments before extracting scripts, so tests would see different code than the browser. Build it as `'<!' + '--'`.
- Modules are compiled in the test's own realm, so `assert.deepStrictEqual` works on the arrays they return. Don't switch to `vm.runInContext`.
- Playwright timed out when opening the SVG file directly. Wrap it in an HTML page with an `<img>` to view it.
- `Object.freeze` throws on a non-empty typed array. Freeze the containing object, but leave `Int32Array`/`Uint8Array` members unfrozen (`Topology` CSR arrays, future terrain arrays).
- Playwright screenshots in this headless setup can lag one frame behind evaluate-driven changes. Take the screenshot twice, or read `#status-message` / `RpgMap.App.State` to confirm the view.

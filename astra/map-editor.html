Landmark on selected tile

One landmark per tile. Replacement keeps its identity; terrain and labels are independent.

Labels

Choose an existing label to locate its anchor. Apply updates that label at the currently selected tile; New label creates another independent label.

Derived map

Source family and world size stay fixed. Finer grids sample centers; coarser grids use greatest covered terrain area. Local extents expand to cover the old outline with default terrain outside it. Landmark collisions stop conversion.

Local global anchor

The local origin maps to this point. Registration uses miles and a planar rotation, not tile matching or automatic seam folding. The parent file is not opened or modified.

Registered coordinates

Lookup uses the anchor's geometric panel. Coordinates outside that face remain planar references, not spherical positions.

Drag to paint; one stroke is one undo step. Wheel to zoom; middle-drag or Alt-drag to pan. With the canvas focused, arrows select local tiles or pan global views, Enter/Space applies the tool, +/- zooms, and Escape cancels a stroke. Ctrl/Cmd+Z undoes, Shift+Ctrl/Cmd+Z or Ctrl+Y redoes, Ctrl/Cmd+S downloads, and Ctrl/Cmd+O opens a file. P adds path points, K places landmarks, and L selects label anchors. Escape also cancels a path draft. Resolution conversion creates a separate map; SVG export comes in a later phase.

Blue tiles are owned by the selected panel; faint tiles belong to its neighbors. Red lines show nominal panel boundaries, not terrain ownership boundaries. This preview uses regional XL spacing and panel-relative north.

The projection has twelve hexagonal panels and six square panels.

Working

Changes are applied only after the operation finishes. Cancel keeps the current map and history.

Export SVG

Export the whole local map or one global panel, including its owned protrusions. SVG is artwork, not an editable map save. Export does not change your map or its save checkpoint.

Export choices are independent of editor visibility. Maximum 25,000 tiles, 500,000 processing operations, and 16 MiB. For larger maps, derive a coarser resolution first.
